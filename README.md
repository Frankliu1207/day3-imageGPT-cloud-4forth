# ImageGPT：2024 年 AI & GPT 课程实践

这是我在 2024 年参加新加坡南洋理工大学 **AI & GPT** 短期课程时，跟随教师示例完成的图片生成网页练习。课程时间为 **2024 年 1 月 29 日至 2 月 2 日**。

当时我刚接触编程和 GitHub，主要按照课堂方法操作，并在遇到问题时向老师和同学请教。本仓库保留了这次早期学习实践的代码和部署过程，不代表独立开发或训练了图片生成模型。

## 项目功能与流程

网页接收用户输入的图片描述，后端通过 Replicate 的模型接口请求生成图片，再将返回的图片地址交给页面展示。

```text
输入图片描述
→ HTML 表单提交
→ Flask 接收请求
→ 调用 Replicate 接口
→ 获取结果并展示图片
```

项目使用：

- Python、Flask：处理网页请求和模板渲染。
- HTML：提供输入表单和图片展示。
- Requests：请求外部模型接口。
- Gunicorn、Render：部署网页服务。

“ImageGPT”沿用当时课堂练习的名称。实际代码调用的是 Replicate 接口，不能仅凭名称将其视为 OpenAI ImageGPT 模型的实现。

## 文件结构

```text
app.py
requirements.txt
templates/
└── index.html
```

- `app.py`：处理表单输入、模型请求和页面返回。
- `requirements.txt`：记录项目依赖。
- `templates/index.html`：网页模板。
